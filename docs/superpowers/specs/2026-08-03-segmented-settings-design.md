# Кнопочный контрол выбора и компактные настройки GUI

Дата: 2026-08-03

## Задача

Три пункта из `docs/TODO.md`:

1. Сделать переиспользуемый контрол выбора из малого числа вариантов — «radiobuttons
   на кнопках» — с поддержкой `defaultValue` и `customValue` (кнопка `...`,
   открывающая ввод произвольного значения). Перевести на него Basic options,
   Silent speed, Sounded speed, Silent threshold, Video codec, Processing mode и
   Theme.
2. Сделать панель настроек компактнее и понятнее: однотипные настройки рядом,
   по возможности в одну строку.
3. Добавить в подсказку к threshold ссылку на статью
   <https://telegra.ph/How-hard-can-you-trim-silence-before-speech-to-text-breaks-08-03>.

Затрагивается только десктопный GUI (`talks_reducer/gui/`). Web UI и OBS dock не
меняются — там уже есть выпадающий список пресетов.

## Решения, принятые при обсуждении

| Вопрос | Решение |
| --- | --- |
| Судьба слайдеров у трёх числовых настроек | Слайдеры удаляются полностью, кнопочная группа — единственный контрол |
| Поведение кнопки `...` | На месте кнопки появляется `Entry`; `Return` фиксирует значение, `Escape`/потеря фокуса отменяют |
| Ряд «Basic options» | Остаются три существующих макро-кнопки, меняется только их отрисовка; выпадающий список `Preset:` не трогаем |
| Компоновка панели | Вариант C: по одной настройке в строке, сгруппированы под тремя негромкими заголовками, ярлыки короче |
| Поле Server URL | Остаётся отдельной строкой, а не уезжает вправо от кнопок |
| Подсказка к threshold | Одна подсказка на всю группу со всеми четырьмя строками + отдельная ссылка `?` на статью |

## Архитектура

### Новый модуль `talks_reducer/gui/segmented.py`

Чистое ядро плюс тонкая обёртка над Tk — так контрол тестируется без реального
Tk, как это уже сделано в `tests/test_gui_layout.py` через подставные переменные.

```python
Option(value, label, tooltip=None)
CustomSpec(minimum, maximum, display_format)

SegmentedChoice(parent, options, *, tk, ttk, variable=None,
                default_value=None, custom=None, tooltip=None, on_change=None)
```

`variable` необязателен. Без него группа не хранит значение сама, а выделение
задаётся снаружи методом `set_selected(value | None)` — этот режим нужен ряду
«Basic options», где выбранную макро-кнопку определяет уже существующая
`update_basic_preset_highlight`.

`on_change` — необязательный обратный вызов после смены значения; нужен ряду
Theme, где сейчас у радиокнопок стоит `command=gui._refresh_theme`.

Чистые функции без Tk:

- `resolve_selection(value, options)` — индекс совпавшего варианта либо `None`,
  что означает «значение показываем в слоте произвольного ввода».
- `parse_custom(text, spec)` — разбор и ограничение диапазоном, `ValueError` на
  нечисловом вводе.

Поведение виджета:

- По одной `ttk.Button` на вариант; клик пишет значение в `variable`.
- Контрол **подписан** на `variable` через `trace_add`, поэтому применение
  пресета или значения из настроек перерисовывает выделение. Контрол никогда не
  является единственным писателем переменной.
- `default_value` — значение, к которому контрол откатывается, если в `variable`
  лежит неразбираемое или выходящее за диапазон значение.
- `custom=None` означает, что слота `...` нет вовсе (кодек, режим, тема).

Слот `...` живёт в трёх состояниях: покой (`...`), ввод (`Entry` на месте
кнопки), зафиксированное значение (кнопка с этим значением, помеченная как
выбранная). Клик по любому из предустановленных вариантов возвращает слот в
состояние покоя.

### Стили

В `talks_reducer/gui/theme.py` добавляются `Segment.TButton` и
`SelectedSegment.TButton`. Они переиспользуют цвета акцента и выделения, уже
вычисленные для `SelectedLink.TButton`, но с рамкой и без подчёркивания —
это кнопки, а не ссылки.

### Изменения в `talks_reducer/gui/layout.py`

`add_slider()` удаляется, три числовые строки переходят на `add_segmented()`.

| Настройка | Кнопки | Диапазон произвольного значения |
| --- | --- | --- |
| Silent speed | 1, 2, 5, 10 | 1–10 |
| Sounded speed | 1, 1.3, 1.5, 2 | 0.75–2 |
| Silent threshold | 0.01, 0.03, 0.05, 0.10 | 0–1 |
| Video codec | h.264, h.265, av1, mp3 | нет |
| Processing mode | Local, Remote | нет |
| Theme | OS, Light, Dark | нет |
| Basic options | No speedup, Silence ×5, Silence ×10 | нет (макро-группа: `variable=None`, выделение через `set_selected`) |
| Keyframe interval | 5 sec, 10 sec, 30 sec, 60 sec | 1–60 |

Keyframe interval живёт не в «Basic options», а в `advanced_frame`, и остаётся на
своём месте — меняется только сам контрол. Значение по умолчанию — 30 sec.

**Контракт, который нельзя ломать.** `apply_preset_to_gui` применяет значения
через `gui._slider_updaters[key]`. Новый контрол регистрирует под теми же
ключами эквивалентный `set_value(str)` и продолжает наполнять `_basic_defaults`
и `_basic_variables`. Благодаря этому пресеты, `update_basic_reset_state` и
`refresh_advanced_preset_selection` продолжают работать без изменений.

Список `gui._sliders`, по которому тема перекрашивает `tk.Scale`, теряет четыре
элемента (три числовые настройки и keyframe interval), но сохраняется: в нём
остаются два слайдера панели Cut video. Важно, что список не становится пустым —
иначе перекраска темы осталась бы без покрытия.

### Компоновка панели «Basic options»

```
Basic options   [No speedup] [Silence ×5] [Silence ×10]

SPEED & SILENCE
Silent      [1] [2] [5] [10] [...]
Sounded     [1] [1.3] [1.5] [2] [...]
Threshold   [0.01] [0.03] [0.05] [0.10] [...]   ?

OUTPUT
Codec       [h.264] [h.265] [av1] [mp3]   ☑ Add codec suffix

PROCESSING & APPEARANCE
Mode        [Local] [Remote]   ✓ Server 192.168.1.5 is ready
Server URL  [http://192.168.1.5:9005        ] [Discover]
Theme       [OS] [Light] [Dark]
```

Заголовки групп — негромкие подписи, за счёт которых ярлыки строк становятся
короче. При выбранном `Local` строка Server URL и текст статуса скрываются через
`grid_remove()`.

### Подсказки и ссылка на статью

- Одна подсказка на всю группу threshold со всеми четырьмя строками:
  - `0.01` — никогда не вырезает голос, глушит только тишину на хорошем микрофоне
  - `0.03` — подходит для большинства случаев и видео с телефона, но может вырезать тихий голос
  - `0.05` — вырежет агрессивно
  - `0.10` — последний разумный предел, до которого можно безболезненно вырезать тишину
- Рядом с группой — `Link.TButton` с текстом `?`, открывающий статью через
  `webbrowser.open`.
- `talks_reducer/gui/tooltips.py` **не меняется**: ссылка живёт вне пузырька,
  поэтому дорабатывать всплывающую подсказку до «наводимой» не нужно.
- Кнопки кодеков получают собственные подсказки с текстом, который сейчас стоит
  в скобках: «faster», «25% smaller», «no advantages», «audio only».

### Оценка размера у keyframe interval

Сейчас рядом со слайдером стоит подпись вида `30s, +1.4%` — прирост размера
относительно кодирования без дополнительных ключевых кадров, который считает
`estimate_keyframe_overhead`. Секунды уходят в подписи кнопок, а процент
остаётся отдельной подписью справа от группы и показывает оценку для **выбранного**
значения: `+1.4%`. Функция `estimate_keyframe_overhead` сохраняется как есть и
вызывается при каждой смене значения, включая ввод произвольного через `...`.

Прятать процент целиком в подсказки не стали: это единственный числовой ориентир,
по которому пользователь выбирает интервал, и он должен быть виден без наведения.

### Статус соединения

Новая машинерия опроса не нужна. `_check_remote_server` уже вызывается при
переключении в remote (`gui/app.py`) и при старте (`gui/preferences.py`). Эти
пути дополнительно выставляют `remote_status_var`, который рисуется рядом с
кнопками режима: `Server <host> is ready` при успехе и сообщение о
недоступности при отказе.

## Изменения поведения

1. **Кнопка «Silence ×5» больше не блокируется.** Сейчас `reset_basic_button`
   переводится в `DISABLED`, когда значения совпадают с дефолтными. Для кнопки
   в группе это противоречиво: то же состояние теперь означает «выбрана».
   `update_basic_reset_state` перестаёт менять состояние виджета и только
   управляет подсветкой. Повторный клик всегда переприменяет значения.
2. **`sounded_speed` 1.3 и 1.5 становятся достижимыми.** Старый слайдер
   квантовал шагом 0.25. Уже сохранённые значения не трогаются: не совпавшее с
   кнопкой значение показывается в слоте `...`.
